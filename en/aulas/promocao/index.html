Lesson 3 · 20 min

Decision card, promotion and rollback

A keep in the lab is not the official version yet. In production, the new version only goes up when the verdict says B won without making anything worse, someone approves it from the five-line card, and there is a way back that deletes nothing. In this lesson you redo the published verdicts from the LOOP-R example, promote, and roll back.

Start the lesson

In this lesson you will

  1. 1Verdict: B_GANHOU, A_SEGUE or AMOSTRA_INSUFICIENTE
  2. 2The five-line decision card
  3. 3Promote: verdict + approval, with a commit
  4. 4Rollback: the link goes back, the folder stays

Goal: read an A/B verdict with guardrails, show the 5-line card, promote only with approval, and roll back without deleting the version.

01 · From verdict to official version, and back

The decidir, promover and reverter commands of the LOOP-R runner. Click each block.

Rollback is not undoing the commit: it is a new commit that changes the link. The whole history stays in git.

Runner invariants: never promote without B_GANHOU + approval, never delete a cycle, a version, or a memory line, never run two experiments at the same time.

02 · The two published verdicts from the example

The LOOP-R vendas-whatsapp example uses SYNTHETIC data (a generator with seeds chosen to reflect designed effects) and simulated human decisions; the agents ran for real. The kit redoes the math on a copy.

Terminal · cost-free rehearsal
K=~/projetos/loop-r-eng-aprende-v72/kit
X=~/projetos/loop-r/exemplos/vendas-whatsapp   # git clone https://github.com/inematds/loop-r ~/projetos/loop-r (SYNTHETIC data)
E=${TMPDIR:-/tmp}/ensaio-aprende/a3; rm -rf $E; L=$E/loop   # a COPY: nothing is written to the loop-r repo
python3 $K/loopr.py iniciar $L --v1 $X/versoes/v1/executor.prompt.md --candidata $X/versoes/v2/executor.prompt.md
echo "## E0001 · H2 (até 80 palavras), tolerância 0 em reclamações"
python3 $K/loopr.py veredito $L --csv $X/dados/execucoes.csv --de 2026-02-02 --ate 2026-04-26 \
  --metrica resposta --minimo 166 --vigiar reclamou:0 --vigiar optout:0.005; echo "saída: $?"
echo "## E0002 · H3 (abrir citando um ponto da avaliação)"
python3 $K/loopr.py veredito $L --csv $X/dados/execucoes.csv --de 2026-05-04 --ate 2026-07-26 \
  --metrica resposta --minimo 212 --vigiar reclamou:0.01 --vigiar optout:0.005; echo "saída: $?"

The same numbers as the published ledger: E0001 with 58/300 against 89/300 (z=2.94) was discarded because of complaints (6 against 1, tolerance 0); E0002 with 58/300 against 88/300 (z=2.85, p=0.004) won. Even with the 0.01 tolerance the example adopted later, E0001 would still fail (Δ=0.0167).

Reading only the test metric is not enough. E0001 had a bigger gain than E0002 and still could not go up: a guardrail went past the tolerance. And the tolerance is agreed before; changing it after seeing the number is rewriting the hypothesis.

03 · Card, promotion, and rollback

Continues the previous block. The card's cost is the sum of the cost.md of cycle 0004 of the example (5 agents, ~392 thousand tokens); the example also records it in reais, the course counts in tokens.

Terminal · cost-free rehearsal
K=~/projetos/loop-r-eng-aprende-v72/kit
E=${TMPDIR:-/tmp}/ensaio-aprende/a3; L=$E/loop   # continues the previous block (verdict B_GANHOU recorded)
python3 $K/loopr.py promover $L; echo "saída: $?"
python3 $K/loopr.py cartao $L --hipotese "H3 — abrir citando a avaliação" --tokens 392000
python3 $K/loopr.py decidir $L aprovado --por "Seu Nome"
python3 $K/loopr.py promover $L; echo "atual → $(readlink $L/versoes/atual)"
python3 $K/loopr.py reverter $L --motivo "resposta caiu no 1º ciclo após a promoção"
echo "atual → $(readlink $L/versoes/atual) · pastas: $(ls $L/versoes | tr '\n' ' ')"
git -C $L log --format=%s
Example from the repository

loop-r: iniciar

The first attempt to promote is refused: good verdict, but nobody approved. After the rollback, atual points to v1 and both folders are still there.

    07 · In three sentences

    VerdictB wins with significance, minimum N and no guardrail outside the tolerance; otherwise A stays.
    ApprovalAt L1, the five-line card goes to the human; without "aprovado", nothing goes up.
    BackRollback is a commit that changes the link and notes the reason; no version is deleted.
